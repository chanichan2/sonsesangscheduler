# 손세상 댄스 연습 일정 분석

댄스 동아리(손세상)의 곡별 연습 일정을 분석하는 정적 웹사이트입니다. Google Spreadsheet에 모은 부원 가용 시간을 Apps Script 웹앱이 JSON으로 내려주면, 이 사이트가 클라이언트 사이드에서 모든 분석/시각화를 수행합니다.

- 빌드 도구 없음 (HTML + CSS + 순수 JS)
- 외부 라이브러리 없음
- 단일 페이지, 한국어 UI

## 산출물

1. **곡별 시간대별 참여 가능 인원 히트맵** — 인원수만 보기 / 상세 명단 보기 / 둘 다 보기 토글
2. **연습 시간 후보 카드** — 2시간 / 3시간 / 둘 다, 점수순 정렬

## 셋업

### 1. Apps Script 웹앱 배포

스프레드시트에서 다음 형식의 JSON을 반환하는 Apps Script 웹앱을 배포합니다.

```json
{
  "ok": true,
  "generatedAt": "2026-05-07T12:00:00Z",
  "settings": {
    "startDate": "2026-05-01",
    "endDate":   "2026-05-13",
    "thresholdPercent": 60,
    "startHour": 9,
    "endHour":   22
  },
  "dates":  ["5/1", "5/2", "..."],
  "songs":  [{ "name": "오리틀걸", "capacity": 7, "leaders": ["현찬"], "members": ["..."] }],
  "availability": {
    "오수인": { "5/1": "O", "5/2": "13~", "5/3": "X" }
  }
}
```

배포 시 액세스를 **모든 사용자**로 설정해야 fetch가 가능합니다. 배포 후 URL을 복사해 두세요.

### 2. URL 설정

`app.js` 상단의 `APPS_SCRIPT_URL`을 본인의 배포 URL로 교체합니다.

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/<배포 ID>/exec";
```

### 3. 로컬 실행

정적 파일이므로 그냥 `index.html`을 더블클릭해도 되지만, 일부 브라우저는 `file://`에서 fetch를 막으므로 간이 서버를 띄우는 편이 안전합니다.

```bash
# Python 3
python3 -m http.server 8080

# Node.js (전역 설치)
npx serve .
```

브라우저에서 `http://localhost:8080`을 엽니다.

### 4. 배포 (선택)

아무 정적 호스팅에 그대로 올리면 됩니다. 가장 간단한 방법:

- **GitHub Pages**: 리포지토리에 push → Settings → Pages → main 브랜치 root 선택. URL은 `https://<유저명>.github.io/<리포지토리명>/`.
- Netlify / Vercel: 폴더를 드래그 앤 드롭만 해도 배포됩니다.

## 가용 시간 표기 규격

| 표기 | 의미 |
|---|---|
| `O` | 전 시간 가능 |
| `X` | 전 시간 불가 |
| `미정` | 전 시간 가능 + 미정 플래그 |
| `X(미정)` | 전 시간 불가 + 미정 플래그 |
| `13~`, `13-` | 13시부터 끝 시간까지 |
| `~17`, `-17` | 시작 시간부터 17시까지 |
| `13~15`, `13:30~17:30`, `16~17:30` | 시간 범위 (분 단위 OK) |
| `13~15,18~` | 콤마로 구분된 복수 시간대 |
| `13~17(미정)` | 시간 범위 + 미정 플래그 (미정은 항상 뒤에) |

규칙:

- 정각이면 한·두 자리 정수, 분이 있으면 `H:MM`
- `-`와 `~` 동일 처리, 공백 무시, 소문자 `o/x` 자동 대문자화
- 빈 셀은 불가로 취급
- `(미정)`은 항상 가장 뒤에 위치
- 분석 범위(`startHour~endHour`) 밖 시간은 자동 클리핑

## 곡정보 시트와 팀장

곡정보 시트의 열 구성: `A 곡명 / B 정원 / C 팀장 / D부터 멤버1..n` (데이터는 4행부터).

- **팀장 열 인식**: 헤더(1~3행)의 C열에 정확히 `팀장`이라고 적혀 있어야 팀장 열로 인식됩니다. 헤더가 없으면 구버전 레이아웃(C열부터 멤버)으로 동작하므로, **Apps Script를 먼저 재배포한 뒤 시트에 열을 삽입**하면 중간에 깨지는 순간이 없습니다.
- **복수 팀장**: 콤마로 구분 — `현찬, 민재` / `현찬,민재` 모두 허용 (전각 콤마 `，`·`、`도 허용).
- **볼드 표시**: 팀장은 해당 곡의 히트맵 상세 명단과 미정 멤버 요약에서 굵게 표시됩니다.
- 팀장 이름은 멤버1~n 열의 이름과 **정확히 일치**해야 합니다 (팀장도 멤버 열에 반드시 포함). 일치하지 않는 팀장이 있으면 화면 상단 배너와 콘솔로 경고합니다.

## 관리자 모드

팀연습 일정 변경(히트맵 셀 클릭 예약/해제), 전체 초기화, TSV 복사는 **관리자만** 할 수 있습니다. 그 외 사용자는 열람, 새로고침, 임계값 슬라이더, 표시 형식 토글만 가능합니다.

- **토큰 설정(서버)**: Apps Script 편집기 → 프로젝트 설정(⚙) → 스크립트 속성에 `ADMIN_TOKEN` 속성을 추가하고 값에 관리자 비밀번호를 넣습니다. 토큰 값은 코드·저장소·문서 어디에도 적지 않습니다.
- `ADMIN_TOKEN`이 설정되어 있지 않으면 서버는 **모든 변경 요청을 거부**합니다 (안전한 기본값).
- **로그인**: 헤더의 **관리자 로그인** 버튼 → 비밀번호 입력. 서버의 `verify` 액션으로 확인되면 브라우저 localStorage에 저장되어 새로고침해도 관리자 모드가 유지됩니다. **로그아웃** 버튼으로 해제합니다.
- 변경 요청(`add`/`remove`/`clear`)에는 토큰이 함께 전송됩니다. 서버가 `unauthorized`를 반환하면(비밀번호 변경 등) 저장된 토큰을 지우고 관리자 모드를 해제하며, 화면의 미반영 변경분은 롤백됩니다.

## 팀연습 TSV 내보내기

헤더의 **팀연습 TSV 복사** 버튼(관리자 전용)을 누르면 지금까지 잡은 팀연습 일정이 탭 구분 텍스트(TSV)로 클립보드에 복사됩니다. 연습일정 스프레드시트(sonsesang2026)의 A2 셀을 선택하고 붙여넣으면 셀별로 들어갑니다.

- 열 구성: `날짜 / 시작시각 / 종료시각 / 곡명 / 연습실(비움) / 참여부원` (헤더 행 미포함)
- 같은 곡·같은 날의 연속 시간 예약은 한 행으로 병합 (14시 + 15시 → `14 / 16`)
- 날짜는 `2026. 7. 1` 형식 문자열 — 시트 붙여넣기 시 날짜로 자동 인식. 연도는 설정의 startDate에서 추론(해 넘김 처리 포함)
- 참여부원은 히트맵과 동일 규칙: 30분 룰 적용, 다른 곡이 선착순으로 차지한 시간은 차감 후 재계산, 부분 참여는 `이름(15~)` / `이름(~16:30)` / `이름(14:30~15:30)`, 미정은 `이름(미정)` 형태
- 현재 데이터와 매칭되지 않는 오래된 예약 key는 건너뛰고 콘솔에 경고

## 분석 룰

- **30분 룰**: 1시간 슬롯과 멤버 가용 범위의 교집합이 30분 이상이면 가능
- **부분 참여 메모**: 슬롯 시작 이후 시작이면 `HH:MM부터`, 슬롯 종료 이전 종료면 `~HH:MM까지`
- **임계값**: 셀의 참여율(인원수/정원)이 임계값 미만이면 흐림 처리. 임계값과 무관하게 50% 미만은 항상 흐림.
- **후보 슬롯**: 연속된 N시간 슬롯에서 모두 가능한 멤버의 교집합. 점수 정렬 — 인원 많이 → 시간 길게 → 미정 적게 → 부분 적게 → 이른 날짜.

## 자체 검증

페이지 로드 시 각 곡에서 무작위 5개 셀을 뽑아 원본 데이터로부터 재계산해 일치 여부를 콘솔에 보고합니다. 불일치 시 화면 상단 배너로 경고합니다.

## 개발자 노트

브라우저 콘솔에서 `window.__test`로 파싱/계산 함수와 중간 데이터에 접근할 수 있습니다.

```js
window.__test.parseAvailability("13:30~17,18~", 540, 1320)
// → { ranges: [[810, 1020], [1080, 1320]], mijeong: false }
```
